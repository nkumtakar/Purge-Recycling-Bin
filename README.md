# Purge-Recycling-Bin
Basic Power Automate Flow that purges the Recycling Bin

Step #1: Create a flow called Purge Recycling Bin. 

Step #2: Go to Actions and search "Empty Recycle Bin" and drag that into the pane

Step #3: Save

Step #4:  For better ease, you can run it as a Desktop Shortcut instead of through the app interface. Go to the home page of Power Automate screen and select the three elipsis dots next to your flow, and click "Create Desktop Shortcut"
